# Agent rules for the `business` branch

This branch holds business docs only; it is public. Before editing, read `README.md` here and the constitution at
https://github.com/Hanzalar/attune/blob/meta/governance/constitution.md.

- Never write an interviewee's name or identifying health details. Use the role IDs listed in `README.md`.
- Never add raw transcripts, recordings, paid reports or real patient records.
- Every claim about a competitor or regulation carries a source link; mark anything unconfirmed as **(unverified)**.
- Record decisions in `decisions.md` as a new ADR, newest first.
